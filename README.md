# React + TypeScript + Vite

This is a React app with TypeScript and SCSS modules.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, start the development server:

```bash
npm run dev
```

## Timer Component Bugs

The Timer component has three intentional bugs:

1. Clicking Start multiple times- speeds up the countdown.
2. The Stop button doesn't stop the timer.
3. The start, stop and reset buttons does not have any spaces.
